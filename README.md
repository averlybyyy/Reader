# Reader 🐾

Тёмная читалка английских книг с русским переводом, транскрипцией и общим словарём.

**Открыть: https://averlybyyy.github.io/Reader/**

## Первый запуск на iPhone

1. Открой ссылку выше в **Safari**.
2. Нажми **«Поделиться» → «На экран „Домой“» → «Добавить»**. Если есть «Открывать как веб-приложение», оставь включённым.
3. Открой **иконку Reader с лапкой**. Загружай книги уже в установленном приложении: Safari и веб-приложение могут хранить данные отдельно.
4. Нажми **«+»** в библиотеке и выбери EPUB или FB2 из приложения «Файлы». Можно выбрать несколько книг сразу. Также поддерживается FB2 в ZIP и простой PDF с текстом. Формат EPUB иногда ошибочно называют EPAB — такое расширение тоже принимается.
5. Для знакомства уже добавлен короткий демонстрационный отрывок «Алисы», а не полная книга. Его можно удалить через меню книги.

## Как читать

- Листай английский текст **вверх и вниз**.
- Листай перевод **влево и вправо**. Горизонтальный жест по области английского текста тоже двигает строку перевода. Вертикальное чтение не двигает русскую строку.
- Нажми на английское слово: сверху откроется карточка без затемнения текста. Русская строка перейдёт к соответствующему фрагменту; найденное русское слово будет подсвечено и по возможности окажется в центре.
- Кнопки в карточке: **зелёная — знаю, жёлтая — учу, красная — не знаю, × — убрать цвет**. Цветными становятся буквы.
- Обычные словоформы объединяются: dog, dogs, dog’s, doggy. Иногда автоматическое определение ошибается. В «Подробнее» можно вручную связать родственные формы.
- «Подробнее» показывает варианты перевода по частям речи, доступные определения и ссылки на Яндекс, Мультитран и Reverso. Произношение — кнопка наушников; наличие голосов зависит от iPhone.
- Нажми название главы для оглавления. Нижний ползунок показывает положение внутри главы и позволяет перемещаться. Лупа ищет слова и фразы **по всей книге**.
- «Aa» меняет размер, шрифт и расстояние между строками. Только тёмная тема.

## Библиотека и слова

У каждой книги есть обложка (если она была в файле), даты загрузки и открытия, процент чтения и твои теги. Одинаковый файл не добавляется повторно. Процент показывает текущую позицию; перемещение назад уменьшает его.

«Мои слова» показывает три категории и их количество. Считаются семьи слов, а не каждое повторение или грамматическая форма. Можно искать слова, менять цвет и скачивать **CSV** или **JSON**. CSV содержит word, translation, ipa, status, updated_at. JSON можно восстановить в Reader через настройки.

## Обновления без потери данных

Адрес Reader остаётся прежним. Код приложения обновляется отдельно от книг и словаря. Когда появится новая версия, нажми **«Обновить»** на плашке. Также есть **Настройки → Проверить обновление**. Не нужно удалять и заново устанавливать иконку.

В будущих просьбах достаточно написать: «Обнови мой Reader: …». Репозиторий `averlybyyy/Reader`, ветка `main`, GitHub Pages из корня. Вручную пользоваться GitHub для обычных обновлений не нужно.

Старые книги из `ReaderAppDB` версии 2 и цвета из `dict_v1` автоматически переносятся в новую схему при открытии на **том же адресе и в том же браузерном хранилище**.

### Резервная копия

**Настройки → Сохранить всё → сохранить JSON в «Файлы» или iCloud Drive.** Копия включает книги, позиции чтения, обложки, теги, словарь и настройки чтения. При восстановлении добавляются недостающие книги и слова; текущие записи с теми же идентификаторами не заменяются. На новом устройстве также восстанавливаются настройки чтения. Кэш машинных переводов не включён: его можно получить повторно.

Данные хранятся локально, не в GitHub и не в аккаунте. Очистка данных Safari, удаление приложения или смена телефона могут удалить их. Для этого и нужна копия. В настройках можно запросить постоянное хранение, но решение принимает браузер.

## Бесплатность и границы

- GitHub Pages бесплатно обслуживает этот публичный репозиторий. Платной подписки Reader, ключей и платежей нет.
- Книги не загружаются на сервер. Для онлайн-перевода сервису передаётся выбранное слово или небольшой фрагмент. Уже переведённые фрагменты сохраняются на устройстве.
- Google Translate подключён через публичный **неофициальный** интерфейс без ключа; он может ограничивать запросы или перестать работать. Резерв MyMemory ограничен примерно 5 000 символами в день. Бесплатный безлимитный качественный перевод с гарантией доступности обещать нельзя.
- Локальная база IPA содержит около 126 тысяч американских произношений. Для редкого слова транскрипция может отсутствовать; она не выдумывается. Новые переводы требуют интернета. После первого полного запуска оболочка, книги, IPA и сохранённые переводы доступны офлайн.
- Сопоставление русских и английских слов приблизительное. При отсутствии подходящего слова показывается нужный фрагмент без ложной подсветки. На краях строки центрирование ограничено её границами.
- EPUB/FB2 без DRM — основные форматы. PDF извлекается в текстовый поток; сложные колонки могут читаться неточно, сканы без текстового слоя не поддерживаются. Если у PDF нет оглавления, навигация идёт по страницам.
- В 2books был **Яндекс.Словарь**: это подтверждается [кодом прежней читалки](https://2books.su/reader/reader.min.js?v=21). Подключение этого сервиса требует своего доступа. Reader не использует чужой сервер или ключи.

Подробные источники и лицензии: [THIRD_PARTY.md](THIRD_PARTY.md).

## Для следующего обновления

Приложение работает без сборки и внешних CDN. `index.html`, `styles.css`, `src/`, `vendor/`, `icons/`, `manifest.webmanifest`, `sw.js` публикуются из корня репозитория. Тестовые книги и скриншоты из `test-results/` не публикуются.

1. Сохранять имя базы `ReaderAppDB`, существующие object stores и ключи. Миграции только добавляют/преобразуют данные в транзакциях, не очищают базу. Не менять origin или путь установки.
2. При каждом релизе менять номер `VERSION` в `src/app.js`, имя кэша в `sw.js`, версию в `package.json`. Все новые необходимые офлайн-файлы добавлять в `ASSETS`.
3. Не включать автоматический `skipWaiting()` при установке. Новая версия активируется явным действием пользователя. Удалять только старые кэши оболочки с префиксом `reader-shell-`, никогда IndexedDB.
4. Запустить `node --test tests/core.test.mjs`. Для полного браузерного теста нужны Playwright, JSZip и pdf-lib. Указать `READER_DEPENDENCIES` с путём к node_modules, запустить `node serve.mjs`, затем `node tests/browser.cjs` (тест использует установленный Chrome на Windows). `tests/make-icons.cjs` дополнительно использует sharp.
5. Проверить настоящий переход ожидающего service worker на новую версию и неизменность книг/словаря, миграцию старой базы, восстановление копии, офлайн-запуск, импорт и мобильную вёрстку.
6. Опубликовать единый коммит в `main` и дождаться GitHub Pages. Проверить реальный адрес и номер версии, не только успешную запись в GitHub.

В версии 2.0.0 пройдены 6 модульных тестов и браузерные проверки: реальный перевод Google, IPA, цвета и словоформы, независимая прокрутка, пакетный импорт EPUB/FB2/PDF, вложенные главы FB2, поиск, экспорт/восстановление, перенос старой базы, офлайн-чтение и сохранность данных при обновлении. Проверено в Chrome с мобильным размером экрана; непосредственное испытание на iPhone Safari выполняет владелица.
